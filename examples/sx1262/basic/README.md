# Basic Example   
Simple send or receive.   

This example targets `tef::boards::meshlink_gateway::v0_5_0` and the SX1262 pinout
used by the Meshlink Gateway v0.5.0 hardware.

Hardware-only settings such as the SX1262 TCXO voltage are taken from
`tef-boards`; this example keeps only the LoRa parameters that may vary by build.
